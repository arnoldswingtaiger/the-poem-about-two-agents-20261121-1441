This repository holds a small Python program written for the make.fun
bounty [the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).
Running it writes a short poem about agency — the power to choose and
to act — to `/output/entry.txt`.

The poem imagines two agents agreeing on one plan: each chooses the
same turn, the turn chooses them back, and walking together is itself
a choice made twice.

## How to run

```sh
python3 main.py
```

That writes the poem to `/output/entry.txt`. The program uses only
the Python 3.13 standard library, takes no input, and makes no
network requests.
