A tiny program that writes one short poem about agency — the power to choose
and to act — to `/output/entry.txt`, entered in the make.fun bounty
[the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

The poem is about two agents agreeing on one plan: neither walks alone, and
the yes between them becomes a road neither could have walked alone.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt`. No network, no input, no
dependencies: Python 3.13 standard library only.
